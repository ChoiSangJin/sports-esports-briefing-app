## 수정한 문제

1. Jolpica가 결과 limit를 100으로 제한하므로 연간 결과 조회는 첫 5라운드에서
   잘렸습니다. 전체 달력에서 선택일의 라운드를 찾아 해당 라운드 결과를 직접 조회합니다.
2. ESPN 취소·연기·중단 상태가 FINAL 또는 예정으로 잘못 표시될 수 있었습니다.
   별도 취소/연기로 표시하고 무효 점수·승자 강조를 제거합니다.
3. ESPN 조회 실패 Future가 캐시에 남아 다시 시도해도 같은 오류를 반환했습니다.
   실패한 리그의 날짜 캐시를 제거해 재시도가 실제 네트워크를 호출하게 합니다.
4. 경기 전·진행 중 AI 요약이 종료 후 영구 캐시로 재사용될 수 있었습니다.
   경기 상태별 v2 키와 저장 상태 검증으로 구분합니다.
5. F1 카드의 긴 결과·리타이어 사유가 작은 화면에서 넘칠 수 있었습니다.
   사용 가능한 폭 안에서 줄바꿈합니다.
6. 시즌 조회 도중 새로고침하면 이전 요청이 새 캐시를 덮어쓸 수 있었습니다.
   요청 세대를 구분해 이전 응답이 갱신된 캐시를 되돌리지 않도록 합니다.

## 확인 범위와 한계

날짜 필터·시즌 종료·캐시·표·기사 공백·Android 하단 여백·키/모델 설정은
회귀 테스트와 정적 분석으로 확인합니다. 서명 APK의 버전·아이콘·실행 코드와
공개 다운로드 체크섬을 배포 전에 확인합니다. 실제 Android 기기 설치,
접근성 서비스, 실제 사용자 Gemini 키의 유료/무료 할당량과 생성 결과는
이번 클라우드 점검으로 확인하지 않았습니다. 기사 검색 서버나 커뮤니티 수집은
기존 기능이 아니므로 이 점검에서 추가하지 않습니다.
